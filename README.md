# english_4u

Học ngữ pháp tiếng Anh cho học sinh THCS lớp 6–9 (Tiếng Anh Global Success) và lộ trình B1 → B2, 30 phút mỗi bài. Giáo viên tạo lớp, soạn và giao bài, chấm tự động theo 8 dạng câu hỏi, nhận xét bài viết và theo dõi lỗi lặp lại của từng học sinh; học sinh đăng nhập bằng tên đăng nhập do giáo viên cấp.

| Thư mục | Nội dung |
|---|---|
| [`web/`](web/) | Website Nuxt 4 + Supabase (vai trò học sinh / giáo viên / admin, đăng nhập tên + mật khẩu, cài được như app). Nội dung bài học nằm trong database Supabase — sửa bằng Table Editor. Xem [web/README.md](web/README.md). |
| `artifact/grammar-b2.html` | Bản lưu của trang một-trang đã đăng trên claude.ai Artifact (không còn build tự động). |
