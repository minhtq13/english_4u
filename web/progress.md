- Dev server cổng 3000 của người dùng có lúc trả lỗi 500 (`oxc-walker: could not resolve a parseSync implementation`), sau đó trả 200; chưa rõ nguyên nhân (có thể `npm install` lại). Để thử giao diện, tôi build rồi chạy `PORT=3100 node .output/server/index.mjs` (cần nạp `.env`) và đặt `E2E_BASE_URL=http://localhost:3100`; nhớ tắt bằng `pkill -f "node .output/server/index.mjs"`.
- Điểm trên lớp: lớp 6T1 chứa dữ liệu người dùng tự nhập, **không ghi vào đó**; thử ghi ở 6T2 và dọn lại (xoá `class_sessions`, `participation_points`, `score_columns` của lớp, và dòng `class_teachers` đã gán).
- Dev server: `cd web && source ~/.nvm/nvm.sh && nvm use && npm run dev` (người dùng tự chạy cổng 3000; không để server nền).
- Tài khoản thử: khoá `DEV_*`, `TEST_*`, `E2E_*` trong `web/.env.test` (gitignored). Mỗi tài khoản chỉ một phiên: chạy Playwright sẽ đăng xuất tab trình duyệt đang dùng cùng tài khoản.
- Các tài khoản đó nằm trên production: chỉ xem; test ghi dữ liệu chỉ chạy khi `E2E_WRITE=1` và tự dọn.
